# Nabdh AI 🎬

منصة عربية لتوليد فيديوهات ناطقة بالذكاء الاصطناعي — نص إلى فيديو وصورة إلى فيديو، بدعم كامل للغة العربية وبدون علامة مائية.

## المميزات
- 📝 تحويل النص إلى فيديو بشخصية ناطقة
- 🖼️ تحويل الصورة إلى فيديو متحرك
- 🌍 دعم متعدد اللغات
- 🚫 بدون علامة مائية
- ⚡ 10 فيديوهات مجانية يومياً

## التقنيات المستخدمة
HTML5, CSS3, JavaScript
